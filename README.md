# Otthon alszik – gyermekgyógyászati díjkalkulátor

Egy oldalas, telepítés nélküli kalkulátor (index.html): a krónikus beteg gyermekek ellátásának várható NEAK-finanszírozása fekvőbetegként (HBCS, ápolási napok) és járóbetegként (OENO-pontok), költség- és fedezetszámítással.

- Adatok: 9/1993. (IV. 2.) NM rendelet 2. és 3. sz. melléklete (OENO, HBCS), a 13/2026. BM rendelet szerinti, 2026. márciusi teljesítményektől hatályos állapot; 43/1999. (III. 3.) Korm. rendelet elszámolási szabályai; alapdíjak a BM–NGM együttes közlemény szerint (210 000 Ft/súlyszám, 2,10 Ft/pont).
- Nem hivatalos becslés; a tényleges finanszírozást a NEAK elszámolása határozza meg.
- Minden számítás a böngészőben fut; beállításokat csak a böngésző helyi tárhelye őriz.

Közzététel: GitHub Pages, egyedi domain: otthonalszik.hu (CNAME fájl).
